Patchbook
---------

src/patchbook.js is a JavaScript port of patchbook.py from the SoundsBrown
fork of Patchbook (https://github.com/soundsbrown/Patchbook), which is based
on PatchBook by Spektro Audio (https://github.com/spektroaudio/Patchbook).
The examples in examples/ other than cable-types.pb come from the same
project.

D2 and D2.js
------------

vendor/d2/d2.js is D2.js, the WebAssembly build of D2 (https://d2lang.com),
unmodified. It is licensed under the Mozilla Public License 2.0; the full
text is in vendor/d2/LICENSE.txt, and vendor/d2/README.md says which
version it is and where its source code is.

D2 includes code and fonts by others, such as Go ports of Dagre (MIT) and
the Eclipse Layout Kernel (Eclipse Public License 2.0). Their notices and
licenses are in vendor/d2/THIRD_PARTY_NOTICES.txt.

Diagrams made with this page embed the parts of the fonts they use: D2's
Source Sans Pro and Source Code Pro by Adobe (SIL Open Font License 1.1), or
the fonts you choose.


Righteous
---------

The page's title is set in Righteous by Astigmatic (fonts/righteous-400.woff2,
the Latin subset from Fontsource 5.3.0). It is licensed under the SIL Open
Font License 1.1; the full text is in fonts/OFL-righteous.txt.
