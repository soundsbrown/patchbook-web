    Patchbook in a nutshell

    // A comment, shown under the diagram

VOICE 1:
- Sequencer (Pitch) p> Oscillator (V/Oct)
- Sequencer (Gate) g> Envelope (Gate)
- Oscillator (Saw) -> Filter (In)
- Envelope >> Filter (Cutoff)

* Oscillator: Wave = Saw | Octave = -1
* Filter:
| Cutoff = 30%
| Resonance = 2 o'clock

    A cable line starts with a dash (-), then the module and output it comes from, the cable type, and the module and input it goes to. The (port) names are optional.

    TypeCable
    ->Audio
    >>CV
    p>Pitch (1V/oct)
    g>Gate
    t>Trigger
    c>Clock

    A line starting with * Module: gives a module's settings, either on the same line with | between them, or one per line starting with |. Put spaces around the =.

    A line ending in a colon, like VOICE 1:, starts a voice. Upper and lower case don't matter in names.
